# Tidy Data Project

## Project Overview:
This project focuses on cleaning and transforming a dataset using tidy data principles. 

My goal is to restructure the data so that: 
- each variable has its own column
- each observation has its own row


## Instructions:
1. install the required libraries:
- bash
- pip install seaborn pandas matlib
2. download data from link provided below
3. open the jupyter notebook and run all files

## Dataset Description
Dataset used: 2008 Olympic Medalists
- Data, https://canvas.nd.edu/courses/131820/files/5931713?wrap=1
- Adapted from Source, https://edjnet.github.io/OlympicsGoNUTS/2008/

Source: provided dataset from Introduction to Data Science Course, Sp 2026

Data was pre-processed by:
- melting columns
- splitting columns
- removing empty cells
