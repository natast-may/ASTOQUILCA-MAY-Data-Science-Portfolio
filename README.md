# ASTOQUILCA-MAY-Data-Science-Portfolio
This directory contains the projects I have worked on during my Introduction to Data Science course, taken Spring 2026 at the University of Notre Dame. Throughout the course, I will learn core machine learning concepts including **model selection**, **feature engineering**, **hyperparameter tuning**, and **model evaluation**.

By the end of this course, I will have created a portfolio of data-driven web applications, integrating exploratory data analysis, and machine learning models to solve practice problems and commincate findings.

## Table of Contents
- [🎵 Basic Streamlit App](basic_streamlit_app/README.md)
    - **What**: This is my first Streamlit web application! It demonstrates how to load data from a CSV file, display a dataframe, and apply basic filters
    - **Why**: This project showcases my ability to create interactive data applications, integrate Python code with a web interface, and provide users with an easy, interactive way to explore datasets.
    - **Skills Displayed**: Data wrangling, pandas, seaborn
      
- [🏅 Tidy Data Project](TidyData-Project/README.md)
    - **What**: I cleaned and transformed the 2008 Olympic Medalists dataset into a tidy format. Using tidy data principles, I ensured that each variable had its own column and each observation was a single row.
    - **Why**: This project demonstrates my ability to work with messy real-world datasets, and apply data cleaning and transformation techniques.
    - **Skills Displayed**: Data reshaping with pd.melt(), string manipulation, column splitting, data visualization
 
- [🍎 Machine Learning Streamlit App](MLStreamlitApp/README.md)
    - **What**: This is an interactive supervised machine learning web app built with Streamlit. Users can upload their own datasets, select a model, tune hyperparameters, and immediately see how their choices affect performance.
    - **Why**: This project bridges the gap between writing ML code and making it usable. Instead of showing results in a notebook, the app experiments with models interactively. It reflects a core skill in applied ML: communicating and deploying models in a way that others can actually use.
    - **Skills Displayed**: Scikit-learn, Streamlit, data pre-processing, interactive hyperparameter tuning, evaluation metrics and visualization 

- [🌷 Unsupervised Machine Learning Streamlit App](MLUnsupervisedApp/README.md)
     - **What**: An interactive web application that allows users to experiment with unsupervised machine learning on datasets (like the World Happiness Report). Users can upload tabular data, select features, and apply algorithms like K-Means, Hierarchical Clustering, and Principal Component Analysis (PCA) to discover patterns.
    - **Why**: This project highlights my ability to implement and deploy machine learning models, build user interfaces for hyperparameter tuning, and communicate complex mathematical results visually using elbow plots, dendrograms, and scatter plots.
    -  **Skills Displayed**: Unsupervised machine learning (Clustering & Dimensionality Reduction), Streamlit UI development, data preprocessing (StandardScaler), model evaluation (Silhouette scores), and advanced data visualization (Matplotlib/SciPy).
